# 前端安全

## 考察重点

资深前端在安全方面的考察重点包括：

### 核心知识点
- **XSS**：反射型、存储型、DOM 型 XSS，防护措施
- **CSRF**：攻击原理、Token 验证、SameSite Cookie
- **注入攻击**：SQL 注入、命令注入、防护方案
- **安全传输**：HTTPS、内容安全策略（CSP）
- **认证授权**：JWT、OAuth、Session 管理
- **安全编码**：输入验证、输出编码、依赖安全

### 实际场景
- 用户输入的安全处理
- 敏感数据的保护
- 第三方依赖的安全审计
- 安全漏洞的排查与修复

---

*安全是前端开发不可忽视的重要环节* 🔒
