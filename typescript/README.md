# TypeScript

## 考察重点

资深前端在 TypeScript 方面的考察重点包括：

### 核心知识点
- **类型系统**：基本类型、联合类型、交叉类型
- **泛型**：泛型约束、条件类型、映射类型
- **高级类型**：工具类型、模板字面量类型、递归类型
- **类型推断**：类型守卫、类型断言、类型推导
- **模块与命名空间**：声明合并、模块解析
- **装饰器**：类装饰器、方法装饰器、属性装饰器
- **类型编程**：类型体操、复杂类型推导

### 实际场景
- 大型项目的类型安全设计
- 工具类型的编写与复用
- 第三方库的类型定义
- 类型与运行时的一致性保证
