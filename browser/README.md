# 浏览器原理

## 考察重点

资深前端在浏览器原理方面的考察重点包括：

### 核心知识点
- **渲染机制**：DOM 树构建、CSSOM、渲染树、重排重绘
- **V8 引擎**：JS 引擎执行流程、内存管理、垃圾回收
- **事件循环**：浏览器事件循环、任务队列、优先级
- **存储机制**：Cookie、LocalStorage、SessionStorage、IndexedDB
- **网络请求**：HTTP 缓存、Service Worker、PWA
- **安全机制**：同源策略、CORS、CSP、XSS/CSRF 防护

### 实际场景
- 性能问题的根源分析
- 内存泄漏的定位与解决
- 跨域问题的解决方案
- 离线应用的实现
