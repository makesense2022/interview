# Vue

## 考察重点

资深前端在 Vue 方面的考察重点包括：

### Vue 2 核心知识点
- **响应式原理**：Object.defineProperty、依赖收集、派发更新
- **模板编译**：模板 AST、渲染函数、虚拟 DOM
- **生命周期**：生命周期钩子、执行顺序、使用场景
- **组件通信**：props、$emit、$parent/$children、provide/inject、Vuex
- **指令系统**：v-if/v-show、v-for、v-model、自定义指令
- **计算属性与侦听器**：computed、watch、深度监听
- **Vue Router**：路由原理、导航守卫、动态路由
- **Vuex**：状态管理、模块化、插件机制

### Vue 3 核心知识点
- **Composition API**：setup、ref、reactive、computed、watch
- **响应式系统**：Proxy、Reflect、响应式原理升级
- **性能优化**：静态提升、Tree Shaking、编译时优化
- **Teleport**：传送门组件
- **Fragment**：多根节点支持
- **新的生命周期**：setup 替代 beforeCreate/created
- **TypeScript 支持**：更好的类型推导
- **Vue Router 4**：组合式 API 支持
- **Pinia**：新的状态管理方案

### 实际场景
- Vue 2 到 Vue 3 的迁移策略
- 大型项目的组件设计
- 性能优化实践
- 状态管理方案选型
- SSR/SSG 实现

---

*Vue 是前端三大框架之一，掌握其原理和最佳实践至关重要* 💚
