# 网络协议

## 考察重点

资深前端在网络协议方面的考察重点包括：

### 核心知识点
- **HTTP/HTTPS**：协议版本、状态码、请求方法、HTTPS 原理
- **HTTP/2 和 HTTP/3**：多路复用、服务器推送、QUIC 协议
- **WebSocket**：实时通信、握手过程、心跳机制
- **TCP/IP**：三次握手、四次挥手、流量控制、拥塞控制
- **DNS**：DNS 解析过程、DNS 缓存、CDN 原理
- **安全**：CORS、CSP、XSS、CSRF、加密算法

### 实际场景
- 接口设计规范
- 实时通信方案选型
- 跨域问题的解决
- 安全漏洞的防护
