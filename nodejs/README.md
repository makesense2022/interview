# Node.js

## 考察重点

资深前端在 Node.js 方面的考察重点包括：

### 核心知识点
- **Node.js 原理**：事件循环、非阻塞 I/O、单线程模型
- **模块系统**：CommonJS、ES Module、模块加载机制
- **异步编程**：回调、Promise、async/await、Stream
- **文件操作**：fs 模块、Buffer、流处理
- **网络编程**：HTTP 模块、WebSocket、TCP/UDP
- **框架生态**：Express、Koa、Nest.js、Fastify
- **性能优化**：集群、PM2、内存管理

### 实际场景
- 全栈开发能力
- 中间层服务开发
- 构建工具开发
- 微服务架构

---

*Node.js 能力是前端工程师扩展技术栈的重要方向* 🟢
