# 性能优化

## 考察重点

资深前端在性能优化方面的考察重点包括：

### 核心知识点
- **加载性能**：资源加载策略、代码分割、懒加载
- **渲染性能**：减少重排重绘、GPU 加速、虚拟滚动
- **运行时性能**：内存管理、算法优化、事件节流防抖
- **网络优化**：HTTP/2、资源压缩、CDN、预加载
- **构建优化**：Tree Shaking、代码压缩、Bundle 分析
- **监控体系**：性能指标、错误监控、用户行为分析

### 性能指标
- **Core Web Vitals**：LCP、FID、CLS
- **FPS**：帧率监控与优化
- **内存**：内存泄漏检测与优化
- **网络**：资源加载时间、首屏时间

### 实际场景
- 首屏加载时间优化
- 长列表渲染优化
- 大量数据处理优化
- 移动端性能优化
