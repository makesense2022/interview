# React

## 考察重点

资深前端在 React 方面的考察重点包括：

### 核心知识点
- **React 原理**：虚拟 DOM、Diff 算法、Fiber 架构
- **Hooks**：Hooks 原理、自定义 Hooks、Hooks 最佳实践
- **状态管理**：Redux、Zustand、Recoil 等状态管理方案
- **性能优化**：Memo、useMemo、useCallback、代码分割
- **SSR/SSG**：Next.js、服务端渲染原理
- **React 18**：并发特性、Suspense、自动批处理
- **组件设计**：组件拆分、设计模式、可复用组件

### 实际场景
- 大型应用的状态管理方案选型
- 性能瓶颈的排查与优化
- 组件库的设计与实现
- 服务端渲染的性能优化
