# 系统设计

## 考察重点

资深前端在系统设计方面的考察重点包括：

### 核心知识点
- **架构设计**：前端架构模式、微前端架构、模块化设计
- **状态管理**：全局状态管理方案、数据流设计
- **组件设计**：组件库设计、组件通信、组件复用
- **性能架构**：缓存策略、CDN 方案、资源加载策略
- **可扩展性**：代码组织、插件化架构、配置化设计
- **团队协作**：代码规范、协作流程、技术选型

### 实际场景
- 大型前端项目的架构设计
- 技术方案的选型与评估
- 团队开发规范的制定
- 系统性能与可维护性的平衡
