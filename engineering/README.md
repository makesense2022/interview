# 前端工程化

## 考察重点

资深前端在工程化方面的考察重点包括：

### 核心知识点
- **构建工具**：Webpack、Vite、Rollup、Turbopack
- **模块化**：ES Module、CommonJS、模块联邦
- **代码质量**：ESLint、Prettier、Husky、Commitlint
- **测试体系**：单元测试、集成测试、E2E 测试
- **CI/CD**：GitHub Actions、Jenkins、自动化部署
- **Monorepo**：pnpm、Lerna、Nx、Turborepo
- **微前端**：qiankun、Module Federation、Single-SPA

### 实际场景
- 大型项目的工程化架构设计
- 构建性能优化
- 开发体验提升
- 团队协作规范制定
