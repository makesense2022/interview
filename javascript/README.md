# JavaScript 核心

## 考察重点

资深前端在 JavaScript 方面的考察重点包括：

### 核心知识点
- **执行上下文与作用域链**：理解代码执行机制
- **闭包**：深入理解闭包的应用场景和内存管理
- **this 绑定**：四种绑定规则及优先级
- **原型链与继承**：理解 JavaScript 的面向对象机制
- **事件循环**：Event Loop、宏任务、微任务
- **异步编程**：Promise、async/await、Generator
- **类型系统**：类型转换、类型判断、Symbol、BigInt
- **模块化**：ES Module、CommonJS、AMD/CMD

### 实际场景
- 内存泄漏的排查与解决
- 复杂异步流程的控制
- 性能优化的底层原理
- 跨模块数据共享与状态管理

*掌握 JavaScript 核心是成为资深前端的基础* 💪
