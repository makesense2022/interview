# 作用域 / this / 闭包（≤6 分复习）

- 【4】词法作用域 vs 动态作用域
  - JS 使用词法作用域：作用域在定义时确定
  - with/eval 会影响静态分析，不建议使用

- 【5】this 绑定 4+1 规则与优先级
  - new > 显式（call/apply/bind）> 隐式（obj.foo()）> 默认（严格模式下为 undefined，非严格为全局）
  - 箭头函数 this 为定义处的词法绑定，忽略上述四类
  - “谁调用是谁”在解构/回调传参时会失效

- 【6】闭包本质与内存
  - 闭包：函数携带其词法环境的能力；环境在可达时被保留
  - 泄漏来源：未清理的定时器/监听器、闭包引用大对象
  - 规避：及时取消、使用弱引用、缩小闭包捕获范围
